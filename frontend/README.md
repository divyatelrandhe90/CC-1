# Frontend

React + Vite presentation layer. Run `npm install` then `npm run dev`.

The deployed site is `https://cc-1-divya.netlify.app/` and its API is `https://cc-1-b4mz.onrender.com/api`. Set `VITE_API_URL` to the API value in Netlify if you want to override the frontend default. Netlify build command: `npm run build`; publish directory: `dist`.
