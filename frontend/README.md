# Frontend

React + Vite presentation layer. Run `npm install` then `npm run dev`.

The deployed site is `https://cc-1-divya.netlify.app/` and its API is `https://cc-1-b4mz.onrender.com/api`. The client normalizes `VITE_API_URL` with or without its `/api` suffix; local development defaults to `http://localhost:5000/api`. Netlify build and SPA routing are configured by the repository root `netlify.toml`.
